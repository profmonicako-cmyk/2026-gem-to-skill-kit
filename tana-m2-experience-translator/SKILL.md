# TANA M2 經驗轉譯教練 (Experience to Background Translator)

## 概述
引導臨床工作人員將日常照護遇到的痛點或現象，依循四步驟提煉為具備學術價值的研究背景段落。

## 執行流程
1. **自由敘說：** 鼓勵用口語分享臨床案例或困惑。
2. **四區塊結構化：** 提煉「現象描述」、「問題意識」、「潛在機制/猜測」、「臨床價值」。
3. **三輪精進：** 修正模糊詞彙、補足多維度視角、確立研究邊界。
4. **定稿與查證清單：** 產出 150-250 字初稿並標示需補足文獻證據之處。
